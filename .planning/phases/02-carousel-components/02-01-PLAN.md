**project-card.ts:**
- Standalone component with selector `app-project-card`
- Input signal for `project` of type `Project` (required)
- Input signal for `isActive` boolean (optional, default false) - for carousel styling
- Import Project interface from `@src/app/core/models/project.model`
- Follow existing component patterns (see card-stacks.ts for reference)

```typescript
import { Component, input } from '@angular/core';
import { Project } from '../../models/project.model';

@Component({
  selector: 'app-project-card',
  standalone: true,
  imports: [],
  templateUrl: './project-card.html',
  styleUrl: './project-card.scss'
})
export class ProjectCard {
  project = input.required<Project>();
  isActive = input<boolean>(false);
}
```

**project-card.html:**
Structure (image-dominant as per CONTEXT.md):
```html
<article class="project-card" [class.active]="isActive()">
  <div class="card-image">
    <img [src]="project().images[0]" [alt]="project().title" loading="lazy" />
  </div>

  <div class="card-content">
    <h3 class="card-title">{{ project().title }}</h3>
    <p class="card-description">{{ project().description }}</p>

    <div class="card-tags">
      @for (tech of project().technologies.slice(0, 3); track tech) {
        <span class="tech-tag">
          <i [class]="'devicon-' + tech.toLowerCase().replace('.', '').replace(' ', '') + '-plain'"></i>
          {{ tech }}
        </span>
      }
    </div>

    <div class="card-links">
      @if (project().githubUrl) {
        <a [href]="project().githubUrl" target="_blank" rel="noopener" class="link-btn github" aria-label="Ver codigo no GitHub">
          <i class="devicon-github-original"></i>
        </a>
      }
      @if (project().demoUrl) {
        <a [href]="project().demoUrl" target="_blank" rel="noopener" class="link-btn demo" aria-label="Ver demonstracao">
          <i class="fa-solid fa-external-link-alt"></i>
          Demo
        </a>
      }
    </div>
  </div>
</article>
```

Note: For demo link icon, use FontAwesome class (already included via CDN in index.html based on codebase patterns). If not available, use a simple arrow unicode character.
